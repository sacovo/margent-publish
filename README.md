# margent-publish

The GitHub Action that publishes a static build to Margent: `action/` (usage in
`action/README.md`) and the `margent` CLI it runs (`cli/`). Setting a repository up,
including Marp decks: `action/SETUP.md`. Pin the action by commit SHA:

    - uses: <this repository>/action@<commit sha>

This repository is a read-only mirror; changes made here are overwritten.
